# Notation de base
- `&` : asynchrone
- `;` : fin de définition OU lancement séquentiel
- `-` : STDIN-as-file.
- `1` : STDOUT.
- `2` : STDERR.
- `>` : Redirection.
- `>>` : Redirection sans écrasement préalable du flux.
- `<` : Apport.
- `<<` : Apport sans écrasement préalable du flux.
- `--` : Fin interprétation des arguments.

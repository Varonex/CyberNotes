# CVE

"Common Vulnerabilities & Exposures". Liste les vulnérabilités communes par date & numéro. Associe un score CVSS.
`CVE-YEAR-NUMBER`
> https://www.cve.org
# Shodan

Recherche d'endpoints via des filtres.
> https://www.shodan.io
# Filtres

- `port:x` : par port.
- `country:fr` : par pays, norme ISO.
- `org:asn` : par organisation (utilise les identifiants ASN).
- `hostname:uri` : par URI (nom de domaine, nom d'hôte).
# VirusTotal

Recherche de comportements malwares sur un fichier, soit par base d'upload, soit par identification & nom.
> https://www.virustotal.com
